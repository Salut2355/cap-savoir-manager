# cap-savoir-manager
Application de gestion du centre CAP SAVOIR

## Lancement local

Prérequis : Node.js (aucune dépendance npm à installer).

Depuis la racine du dépôt, lancer `node tools/serve-local.js`, puis ouvrir
`http://localhost:8080`. Arrêter le serveur avec `Ctrl+C`.

Les données de l'application sont stockées localement dans le navigateur. Le
serveur de développement ne configure aucun compte, API ni service Cloudflare.
